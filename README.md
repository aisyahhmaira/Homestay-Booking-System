# Velvet Valley Stays — Homestay Booking System

A full-stack homestay booking web application built with **Java, Spring Boot, HTML, CSS, JavaScript, and H2 Database**.

## Project Overview

Velvet Valley Stays is a university project that allows guests to browse homestay rooms, check availability, and make reservations online. It also includes an admin interface for managing room listings and viewing booking records.

The application uses Spring Boot for backend functionality, HTML/CSS/JavaScript for the frontend, and H2 Database for data storage during development and testing.

## Key Features

### Guest Features
- Register and log in to the application.
- Browse available rooms and room details.
- Select check-in and check-out dates, number of guests, and room type.
- Check room availability and make reservations.
- Receive booking confirmation.

### Admin Features
- View guest booking records.
- Add new room listings.
- Update existing room information.
- Delete room listings.

## How the Application Works

### Guest Booking Flow
1. The guest registers or logs in.
2. The guest enters the check-in date, check-out date, number of adults and children, and room type.
3. The application checks room availability for the selected criteria.
4. The guest confirms the reservation.
5. The application displays a booking confirmation message.

### Admin Management Flow
1. The admin opens the management interface.
2. The admin views booking records.
3. The admin can add new rooms, edit existing room information, or delete rooms.
