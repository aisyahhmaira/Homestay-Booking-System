# Velvet Valley Stays — Homestay Booking System

A full-stack homestay booking web application built with **Java, Spring Boot, H2 Database, HTML, CSS/SCSS, and JavaScript**.

## Project Overview

Velvet Valley Stays is a university project designed to support the main activities of an online homestay booking platform. Guests can browse available rooms, enter their stay details, and make reservations. An admin interface supports room management and provides access to booking records.

The project demonstrates how a web interface communicates with a Java backend through REST APIs, with H2 used for database operations during development and testing.

## Key Features

### Guest Features
- **Browse rooms:** Explore available homestay room listings.
- **User access:** Register and log in to use the application.
- **Booking details:** Enter check-in and check-out dates, number of adults and children, and preferred room type.
- **Availability checking:** Check room availability based on the selected dates and room type.
- **Reservation:** Confirm a booking and receive a confirmation message.

### Admin Features
- **View bookings:** Access a list of booking records.
- **Add rooms:** Create new room listings.
- **Update rooms:** Modify details of existing rooms.
- **Delete rooms:** Remove rooms that are no longer available or needed.

## How the Application Works

### Guest Booking Flow
1. The guest registers or logs in.
2. The guest enters the check-in date, check-out date, number of adults and children, and room type.
3. The application checks room availability for the selected criteria.
4. The guest confirms the reservation.
5. The application displays a booking confirmation message.

### Admin Management Flow
1. The admin opens the management interface.
2. The admin views booking records.
3. The admin can add new rooms, edit existing room information, or delete rooms.
