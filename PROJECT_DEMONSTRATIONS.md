# Velvet Valley Stays — Project Demonstrations

This page contains video demonstrations of **Velvet Valley Stays**, a full-stack homestay booking web application developed using Java, Spring Boot, H2 Database, HTML, CSS/SCSS, and JavaScript.

The videos cover the project presentation, website interface, guest booking process, and admin management features.
