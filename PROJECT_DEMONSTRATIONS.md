# Velvet Valley Stays — Project Demonstrations

This page contains video demonstrations of **Velvet Valley Stays**,a full-stack homestay booking web application developed using Java, Spring Boot, H2 Database, HTML, CSS and JavaScript.

These videos showcase the main application features, including guest reservations, room management and website navigation.
